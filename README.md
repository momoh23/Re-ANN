Re-ANN: A retrofitting energy controller for Artificial Neural Network development 

@Copyright: Dr. Mohamed Kentour
University of Huddersfield, UK

A new variational controller for sequential and parallel deep neural network simulations. Re-ANN integrates the Proportional Integral Derivatives into the CPU feedforward cores and the GPU backpropagated error signal approximation.
In Re-ANN, the CPU hardware cores and the GPU are orchestrated to perform a shift of neural network architectural design, multi fine-tuned workers (neuro models) collaborate within a desired target training time and a very reduced cycle.
